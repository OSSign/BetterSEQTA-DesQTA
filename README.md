# OSSign Information
## What's this?
This is a repository used for creating signed binaries for the [BetterSEQTA/DesQTA](https://github.com/BetterSEQTA/DesQTA/) project.

## Where are the signed binaries published?
The signed drivers are published by the author on [BetterSEQTA/DesQTA](https://github.com/BetterSEQTA/DesQTA).

You can find the latest workflow runs for the build and signing process in the [Actions tab](https://github.com/ossign/BetterSEQTA-DesQTA/actions).
